## 📌 Overview

**User Management REST API** is a backend project built as **Project 2 of my Decode Labs Internship**. It exposes a clean REST API where clients can check the server status, create users, and fetch the list of all users.

It is built with **FastAPI** and **Pydantic**, so every request is validated automatically, and interactive API documentation is generated for free.

## ✨ Features

- ✅ **Health-check endpoint** to confirm the API is running
- 👤 **Create users** with a name, email, and age
- 📋 **List all users** in one request
- 🔢 **Auto-generated unique IDs** for every new user
- 🛡️ **Automatic request validation** with Pydantic models (invalid data returns a clear `422` error)
- 📖 **Interactive API docs** with Swagger UI (`/docs`) and ReDoc (`/redoc`), generated by FastAPI
- ⚡ **Runs on Uvicorn**, a fast ASGI server

## 🚀 Getting Started

### Prerequisites
- Python 3.10 or higher (recommended)
- pip

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/tejvarmaa-9458/DecodeLabs-Internship-2.git
cd DecodeLabs-Internship-2

# 2. (Optional) Create a virtual environment
python -m venv venv
source venv/bin/activate      # On Windows: venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Start the server
uvicorn main:app --reload
```

The API is now running at **http://127.0.0.1:8000**

📖 Try it in your browser: **http://127.0.0.1:8000/docs**

## 🔌 API Reference

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/` | Checks that the API is running |
| `GET` | `/users` | Returns all users |
| `POST` | `/users` | Creates a new user |

### User Model

| Field | Type | Description |
|-------|------|-------------|
| `name` | string | Full name of the user |
| `email` | string | Email address of the user |
| `age` | integer | Age of the user |

### Examples

**`GET /`**

```json
{ "message": "Project 2 Backend API is running" }
```

**`POST /users`**

```json
// Request body
{
  "name": "Asha Rao",
  "email": "asha@example.com",
  "age": 21
}

// Response
{
  "message": "User created successfully",
  "user": {
    "id": 1,
    "name": "Asha Rao",
    "email": "asha@example.com",
    "age": 21
  }
}
```

**`GET /users`**

```json
[
  {
    "id": 1,
    "name": "Asha Rao",
    "email": "asha@example.com",
    "age": 21
  }
]
```

### Try it with cURL

```bash
curl -X POST http://127.0.0.1:8000/users \
  -H "Content-Type: application/json" \
  -d '{"name": "Asha Rao", "email": "asha@example.com", "age": 21}'

curl http://127.0.0.1:8000/users
```
